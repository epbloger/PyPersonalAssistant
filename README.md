# 🤖 PyPersonalAssistant

![Python](https://img.shields.io/badge/Python-3.x-3776AB?style=for-the-badge&logo=python&logoColor=white)
![Status](https://img.shields.io/badge/Status-Active-success?style=for-the-badge)

> **The most recent personal assistant written in Python.**

---

## ✨ What can it do?

| Feature | Description |
|---|---|
| 🎥 **Movies** | Which movie to watch. |
| 🔢 **Numbers** | Perform basic actions with numbers. |
| 📅 **Date** | Tell you today's date. |
| 🎲 **Random** | Give you a random number. |
| 🎵 **Songs** | Recommend a song. |
| 🔄 **Words** | Reverse the word. |

---

## 🛠 Customization

The list of movies and songs is **pre-programmed** in the code, but there is a function to **add your own movies and songs** to the assistant.

---

## 🎮 Usage

The **full instructions** will be provided when you start the program — you will not get confused and will easily figure it out :)
